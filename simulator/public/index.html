Địa chỉ trên là gợi ý, chưa phải API có sẵn trong project cũ. Flow dùng MQTT Trigger cần thêm HTTP Webhook và map dữ liệu từ body. Xem README để nối đúng.

Điền cấu hình mẫu cho V2

Chỉ điền vào biểu mẫu. Kiểm tra địa chỉ rồi bấm Lưu cấu hình để áp dụng. Giữ nguyên định danh thiết bị và các cảm biến.

Flow01: chỉ telemetry đi qua n8n; heartbeat, claim và ACK vẫn đi thẳng backend. Chưa phải đường tích hợp đầy đủ flow01–06.

Nhận lệnh từ n8n

POST tới http://localhost:4310/api/commands. Nếu n8n chạy Docker Desktop trên Windows, dùng http://host.docker.internal:4310/api/commands và đặt HOST=0.0.0.0 trong .env.

{
  "command_id": "mot-id-duy-nhat",
  "device_id": "ESP32_A101",
  "command_type": "FAN",
  "action": "ON"
}

Có thể nhận FAN, LIGHT, VENTILATION, DEHUMIDIFIER với ON/OFF. Đây là simulator độc lập; chưa thay các workflow hoặc API của nhóm.
